# Seed fotók

A `npm run db:seed` innen tölti fel a demó ingatlanok fotóit. Ha a mappák üresek, az app a
látványterv tónusos helykitöltőit mutatja — minden más működik.

| Mappa | Tartalom |
|---|---|
| `exterior-house/` | családi ház, ikerház, sorház külső fotók |
| `exterior-flat/` | társasház, lakás külső / utcakép |
| `interior/` | nappali, konyha, háló, fürdő |
| `plot/` | telek, kert |
